Helix.set_parameters#

Helix.set_parameters(pitch, width, thickness, diameter, turns)#

This method sets the parameters of the helix

Parameters:

  • pitch (float) – the pitch, or the period of the helix

  • width (float) – the width of the helix

  • thickness (float) – the thickness of the helix

  • diameter (float) – the diameter of the circle containing the helix.

  • turns (float) – the amount of turns made by the helix

Returns:

None – The attributes are set
